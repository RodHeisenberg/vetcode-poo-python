# VetCode | Laboratório de Orientação a Objetos

Material didático público do **Professor Rodrigo**, voltado à prática de orientação a objetos em Python.

## Objetivo

Construir, em grupos, um protótipo para organizar os dados de animais e responsáveis de uma clínica veterinária. O grupo trabalhará com classes, objetos, atributos, métodos, encapsulamento e associação entre objetos.

## Instruções para os alunos

1. Abram a página do laboratório e leiam a situação-problema.
2. Formem equipes de 3 ou 4 pessoas e distribuam as funções de leitura, codificação, revisão e testes.
3. Resolvam as sete etapas em sequência. Ao escrever Python, substituam os comandos `pass` e completem os trechos solicitados.
4. Na última etapa, montem e copiem o código Python produzido pela equipe.
5. Acessem [Google Colab](https://colab.research.google.com/), criem um notebook em branco, colem o programa em uma célula e executem.
6. Se o programa falhar, voltem ao laboratório, ajustem o código e executem novamente no Colab.
7. Após os quatro testes concluídos no Colab, liberem e tentem o desafio extra do menu de consulta.

**Tempo-base:** 40 minutos, com desafio extra para quem terminar antes.

**Importante:** as verificações do site identificam elementos esperados no código, mas não executam Python e não substituem os testes reais no Colab.

## Como publicar no GitHub Pages

1. Crie um repositório público no GitHub.
2. Coloque `index.html`, `styles.css` e `app.js` na raiz do repositório.
3. Em **Settings > Pages**, escolha **Deploy from a branch**, `main` e `/ (root)`.
4. Salve e aguarde o GitHub disponibilizar a URL da página.

Não é necessário instalar bibliotecas, nem configurar back-end. O progresso fica salvo no armazenamento local do navegador em uso. A página não envia as respostas a um servidor.
